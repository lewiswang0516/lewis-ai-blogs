# Handover: homepage and i18n

## Goal

The blog is bilingual.
English is the default language and is served without a prefix.
Simplified Chinese is served under `/zh/`.
The homepage shows a short intro, GitHub and portfolio links, and the latest posts.

## Current state

Done and deployed to `blogs.lewiswang.com.au`.

- Routes: `/`, `/blog/`, `/blog/<slug>/`, `/rss.xml` for English, and the same paths under `/zh/` for Chinese.
- Both posts on saving tokens exist in both languages.
- The Astro template sample posts, placeholder images and About page are removed.

## How it works

- `astro.config.mjs` sets `i18n` with `defaultLocale: 'en'` and `prefixDefaultLocale: false`. The sitemap writes `hreflang` links for both languages.
- Posts live in `src/content/blog/<lang>/<slug>.md`. `getPosts(lang)` in `src/i18n/utils.ts` reads the language from the folder name. A post outside a language folder fails the build on purpose.
- A translated pair uses the same file name in both folders. `getPostPaths` links the pair through `alternates`, which drive the `hreflang` tags and the language switch in the header.
- If a post has no translation, the language switch goes to the other language's homepage instead.
- UI strings are in `src/i18n/ui.ts`. Add every new key to both `en` and `zh`. The build does not run a type check, so a missing `zh` key shows up as empty text.
- Pages in `src/pages` and `src/pages/zh` are thin wrappers. The real markup is in `HomeView`, `BlogIndexView` and `PostView` in `src/components`.
- RSS: `src/i18n/rss.ts` builds one feed per language.
- Dates use `en-AU` or `zh-CN` and the `Australia/Brisbane` time zone.

## Key files

- `src/i18n/ui.ts`, `src/i18n/utils.ts`, `src/i18n/rss.ts`
- `src/components/Header.astro`, `Footer.astro`, `SocialLinks.astro`, `PostList.astro`, `HomeView.astro`, `BlogIndexView.astro`, `PostView.astro`
- `src/layouts/BlogPost.astro`

## How to run and check

- `npm run build`, then `npx astro preview` and open `/` and `/zh/`.
- Check that the language switch on a post opens the same post in the other language.

## Known issues and open questions

- The body background gradient from the template ends in a visible line on short pages.
- Post titles are very large on phone screens (template style).
- Chart images are generated by a script that is not in the repo. To change a chart, regenerate both `tokens-per-turn.svg` and `tokens-per-turn-en.svg`.
